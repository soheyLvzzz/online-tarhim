# راهنمای محیط توسعهٔ انتشار اول

این راهنما برای لندینگ استاتیک React/TypeScript/CSS با Vite است. backend، دیتابیس، ORM و secret سرویس برای دامنهٔ مصوب فعلی لازم نیستند.

## ابزار و نصب

محیط بررسی‌شده Node.js نسخهٔ 24.22.1، npm نسخهٔ 11.9.0 و Python نسخهٔ 3 برای ابزارهای پیش‌نمایش است. نسخهٔ مشاهده‌شدهٔ Node در .node-version ثبت شده است. engines پروژه با حداقل نیاز Vite موجود هماهنگ است: ^20.19.0 یا >=22.12.0.

برای نصب بازتولیدپذیر در یک محیط تازه، داخل پوشهٔ پروژه npm ci اجرا شود. package-lock.json همراه سورس است. در این فاز تطابق نصب موجود با lockfile بررسی شد؛ نصب تمیز روی دستگاه تازه اجرا نشده است. ساخت موفق فعلی ادعای نصب تمیز یا ممیزی آسیب‌پذیری نیست.

## فرمان‌ها

| فرمان در ریشهٔ پروژه | نتیجه |
| --- | --- |
| npm run dev | اجرای سرور توسعهٔ Vite؛ در محیط مدیریت‌شده باید از سرویس preview مجاز استفاده شود. |
| npm run typecheck | بررسی TypeScript با tsc --noEmit. |
| npm test | اجرای پنج تست هوک ورود و دو تست ساخت پیش‌نمایش. Python 3 برای دو تست Python لازم است. |
| npm run check | اجرای بررسی TypeScript و هفت تست موجود. |
| npm run build | بررسی TypeScript و ساخت خروجی قابل میزبانی در dist. |
| python3 scripts/make-preview.py | پس از build، ساخت preview.html مستقل برای بازبینی آفلاین. |

preview.html و dist تولیدی‌اند و در Git ثبت نمی‌شوند. preview.html و فایل OPEN قبلی برای بازبینی هستند؛ سورس و node_modules و docs نباید روی پوشهٔ عمومی هاست بارگذاری شوند.

## متغیرهای محیطی

نسخهٔ فعلی هیچ متغیر محیطی الزامی ندارد. .env.example این عدم نیاز را توضیح می‌دهد. فایل‌های .env واقعی از Git مستثنا هستند؛ ساخت فایل واقعی یا دریافت رمز در این مرحله لازم نیست. متغیرهای VITE_* داخل باندل عمومی قرار می‌گیرند و محل نگهداری رمز یا توکن خصوصی نیستند.

## مدیریت نسخه

مخزن Git محلی روی شاخهٔ main ایجاد می‌شود و نسخهٔ پایه در یک commit محلی ثبت می‌شود. تا دریافت مقصد، remote و push نداریم. داخل تحویل این فاز، فایل online-tarhim-local.git.bundle برای بازیابی تاریخچهٔ محلی قرار می‌گیرد؛ مخزن آنلاین محسوب نمی‌شود.

بازیابی روی دستگاهی با Git: git clone online-tarhim-local.git.bundle online-tarhim سپس ورود به پوشه و اجرای npm ci. فایل bundle شامل سورس و مستندات است، نه node_modules، build یا credential. Git به اینترنت وابسته نیست تا bundle محلی clone شود؛ نصب npm بسته به cache یا دسترسی registry ممکن است به شبکه نیاز داشته باشد.

## محدودیت کنترل کیفیت

TypeScript در حالت strict فعال است. تست‌های موجود، بخشی از منطق انیمیشن و ساخت پیش‌نمایش را می‌سنجند. ESLint، formatter و CI در این فاز نصب یا راه‌اندازی نشدند؛ سلامت کامل رابط، امنیت، سئو یا تجربهٔ موبایل با این تست‌ها تأیید نمی‌شود. dependency جدیدی نصب نشده است.
