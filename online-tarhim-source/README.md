# آنلاین ترحیم — نسخهٔ ۱۷

هفت سکشن نخست لندینگ با React، TypeScript و CSS، براساس فیگما و اصلاحات تأییدشدهٔ کاربر.

## مشاهده

ZIP را استخراج و فایل `OPEN-online-tarhim-v17.html` را باز کنید. تصویرها، فونت‌ها، SVGها و برنامه داخل همین HTML قرار دارند؛ نصب چیزی لازم نیست.

## تغییرات نسخهٔ ۱۳

- فاصلهٔ اول تا دوم ۱۶۰ پیکسل حفظ شده است؛ فاصلهٔ دوم تا سوم و سوم تا چهارم هرکدام ۸۰ پیکسل است.
- کارت‌ها به چیدمان نسخهٔ ۸ برگشته‌اند: سه کارت ۴۲۶×۴۶۹ پیکسل، فاصلهٔ میان کارت‌ها ۳۱ پیکسل، ردیف به عرض ۱۳۴۰ پیکسل و وسط‌چین در قاب ۱۴۴۰ پیکسلی.
- هدینگ بخش سوم ۸۰ پیکسل از سقف پس‌زمینه فاصله دارد. فاصلهٔ هدینگ تا کارت‌ها ۴۸ پیکسل و فضای داخلی پایین بخش ۸۰ پیکسل است. ارتفاع کل بخش سوم اکنون ۷۶۲ پیکسل است.
- برچسب «انتخاب متداول خانواده ها» فقط روی کارت وسط و از حالت عادی دیده می‌شود. هاور کادر طلایی و دکمهٔ گرادیانی هر سه کارت حفظ شده است.
- جای متن‌ها و هدر و پس‌زمینه‌های تمام‌عرض تأییدشدهٔ دو بخش نخست حفظ شده‌اند.

## سکشن چهارم — سایر خدمات

مطابق فریم Services فیگما، شش کارت در دو ردیف و سه ستون از راست به چپ اضافه شده‌اند. قاب محتوا ۱۳۴۰ پیکسل و پس‌زمینهٔ `#181818` تمام‌عرض است. فاصله از بخش سوم ۸۰ پیکسل، فضای داخلی بالای هدینگ ۸۰ پیکسل، فاصلهٔ هدینگ تا جدول ۳۲ پیکسل و فضای داخلی پایین ۸۰ پیکسل است. ارتفاع کل این بخش ۸۱۵ پیکسل است.

تمام هشت SVG جدید ارسالی کاربر بدون تغییر استفاده شده‌اند: شش آیکون ۳۲×۳۲، قاب آیکون ۷۲×۷۲ و پیکان ۱۷×۱۰. رنگ متن‌ها `#E2E2E2`، توضیحات `#A6A6A6`، خطوط جدول `#343434` و رنگ تأکیدی `#D1C56C` است.

ردیف «اطلاعات بیشتر» هاور دارد: متن به رنگ روشن با زیرخط طلایی تغییر می‌کند و فلش اصلی طی ۲۲۰ میلی‌ثانیه ۳ پیکسل به چپ می‌رود و کمی محو می‌شود. این رفتار با فوکوس صفحه‌کلید هم فعال است و با کاهش حرکت سیستم جابه‌جایی غیرفعال می‌شود. کارت‌ها و آیکون‌های خدمات هاور ندارند. عنوان و کارت‌ها هنگام ورود به دید با محوشدن و حرکت ملایم ۶ پیکسلی ظاهر می‌شوند. کاهش حرکت سیستم و فوکوس صفحه‌کلید رعایت می‌شوند.

دکمه‌ها رویداد `tarhim:service-details` با شناسهٔ خدمت منتشر می‌کنند. صفحات جزئیات جزو این مرحله نیستند؛ هنگام ادغام، callback `onMore` به مسیر واقعی وصل می‌شود.

## اجرا و ساخت

ترمینال را در پوشهٔ پروژه باز کنید:

```bash
npm ci
npm run dev
```

برای بررسی TypeScript و ساخت:

```bash
npm run build
```

خروجی میزبانی در `dist` است. برای ساخت HTML مستقل:

```bash
python3 scripts/make-preview.py
```

این اسکریپت فایل محلی `preview.html` را می‌سازد؛ در ZIP همین خروجی با نام مخصوص نسخهٔ ۱۳ آمده است. اسکریپت فایل‌های دقیق معرفی‌شده در `dist/index.html` را می‌خواند و فایل‌های قدیمی پوشهٔ assets را انتخاب نمی‌کند. تست‌های این رفتار در `scripts/test_make_preview.py` هستند.

## محدوده و بررسی

- هیرو، درباره، پلن‌ها و سایر خدمات پیاده‌سازی شده‌اند؛ صفحات سفارش، پرداخت و دیگر بخش‌های لندینگ در محدوده نیستند.
- منو و دکمه‌های هیرو رویداد `tarhim:navigate` و دکمه‌های پلن رویداد `tarhim:request-plan` منتشر می‌کنند؛ هنگام ادغام با پروژه باید به مسیریاب یا فرم واقعی وصل شوند. شمارهٔ تماس لینک واقعی `tel:` دارد.
- تصویرها، لوگو، فونت‌ها و SVGهای نشانهٔ فهرست و آیکون تلفن همان فایل‌های ارسالی کاربر هستند. جداکنندهٔ افقی کارت‌ها با CSS ساخته شده است؛ دریافت SVG این خط از فیگما با خطای شبکه مواجه شد.
- انیمیشن‌ها ملایم و بدون تکرارند؛ کاهش حرکت سیستم و فوکوس صفحه‌کلید رعایت شده‌اند.
- نسخهٔ موبایل تأیید نشده و چیدمان دسکتاپ حداقل ۱۴۴۰ پیکسل دارد.
- بررسی TypeScript و ساخت Vite موفق بود. پیش‌نمایش مستقل و یکپارچگی ZIP بررسی شدند. بررسی بصری مرورگر انجام نشده، چون سرویس پیش‌نمایش محیط در دسترس نیست.
- استقرار انجام نشده است.

## اصلاحات نسخهٔ ۱۳

پس‌زمینهٔ سکشن سوم مشکی خالص `#000000` شد. فقط دو فاصلهٔ دوم تا سوم و سوم تا چهارم به ۸۰ پیکسل کاهش یافته‌اند؛ فاصلهٔ اول تا دوم و اندازه و چیدمان کارت‌ها و متن‌های تأییدشده حفظ شده‌اند.

## سکشن پنجم — آرشیو مجالس (نسخهٔ ۱۳)

چهار کارت ۳۲۰×۳۷۱ پیکسلی در ردیف ۱۳۴۰ پیکسلی با فاصلهٔ ۲۰ پیکسل؛ تصویر اصلی ارسالی در جایگاه ۳۲۰×۲۲۰ و SVG پخش ۲۴×۲۴ استفاده شده است. فاصله از سکشن چهارم ۸۰ پیکسل، فضای داخلی بالا و پایین هرکدام ۸۰ پیکسل و فاصلهٔ هدینگ تا کارت‌ها ۴۰ پیکسل است. پس‌زمینه تمام‌عرض مشکی خالص است. کادر عادی هر چهار کارت #343434 و کادر هاور یا فوکوس #D1C56C است؛ کارت اول از ابتدا حالت هاور ندارد. انیمیشن ورود آرام و پشتیبانی از کاهش حرکت سیستم برقرار است.

دکمهٔ مشاهده، رویداد tarhim:view-archive با ceremonyId را برای اتصال بعدی منتشر می‌کند؛ صفحهٔ نمایش مراسم در محدودهٔ این مرحله نیست. تاریخ و محتوای تکراری کارت‌ها مطابق طرح فیگما هستند. خط جداکننده با CSS مثل نسخه‌های قبل ساخته شده؛ دریافت SVG خط از فیگما خطای Site Unavailable داد.

ساخت Vite و TypeScript و دو تست پیش‌نمایش موفق بودند. سرویس sites-previewd در محیط در دسترس نبود؛ بررسی بصری مرورگر انجام نشده است.

## نسخهٔ ۱۴ — اصلاح تعامل و سکشن ششم

در سکشن‌های سوم تا پنجم، قانون قطع انیمیشن با focus-within حذف شد؛ پس از اولین pointerdown یا focusin، ورود بخش به حالت پایدار می‌رود و با برداشتن فوکوس دوباره اجرا نمی‌شود. هاور و فوکوس ظاهری حفظ شده‌اند. Hook مشترک از تکرار ورود پس از تعامل یا تغییر تنظیم کاهش حرکت جلوگیری می‌کند و listenerها هنگام unmount حذف می‌شوند. این دکمه‌ها type=button دارند و همچنان رویدادهای اتصال به صفحات بعدی را منتشر می‌کنند؛ صفحه‌های مقصد هنوز پیاده نشده‌اند.

سکشن اخبار براساس فیگما 72:458 با پس‌زمینهٔ تمام‌عرض #1D1D1D، فاصلهٔ بیرونی ۸۰ پیکسل، فضای داخلی بالا و پایین ۸۰ پیکسل و ارتفاع کل ۹۰۰ پیکسل اضافه شد. تصویر ارسالی در جایگاه ۶۶۰×۴۵۰ با برش object-fit:cover قرار دارد. سمت راست مقالهٔ اصلی و سمت چپ سه مقالهٔ فهرست هستند. فقط کنترل «مطالعه مقاله» هاور دارد: متن روشن و زیرخط طلایی می‌شود؛ فلش اصلی خدمات طی ۲۲۰ میلی‌ثانیه ۳ پیکسل به چپ حرکت می‌کند و opacity آن به ۰٫۸ می‌رسد. فوکوس صفحه‌کلید و کاهش حرکت سیستم پشتیبانی می‌شوند. عکس و کارت‌ها هاور ندارند.

متن و تاریخ همان مقادیر نمایشی فیگما هستند. رویداد tarhim:read-article با articleId برای اتصال بعدی منتشر می‌شود. SVG فلش جدید از فیگما دانلود نشد (Site Unavailable)؛ مطابق درخواست استفاده از هاور سکشن چهارم، همان SVG فلش موجود استفاده شد. جداکننده‌ها مانند بخش‌های قبلی با CSS ساخته شده‌اند.

بررسی‌ها: node --test scripts/test_scroll_reveal.cjs (۵ تست)، npm run build (TypeScript و Vite)، python3 scripts/make-preview.py و python3 -m unittest discover -s scripts -p 'test_*.py' (۲ تست) موفق بودند. سرویس sites-previewd در دسترس نیست؛ آزمون تعامل در مرورگر و تطبیق تصویری تأیید نشده‌اند.

## نسخهٔ ۱۵ — رفع هاور ماندگار و کارنامه

استایل‌های focus-within کارت‌های پلن و آرشیو به :has(:focus-visible) تغییر کردند. بنابراین فوکوس باقی‌مانده پس از کلیک ماوس، حالت هاور را نگه نمی‌دارد؛ پس از خروج نشانگر ظاهر عادی برمی‌گردد. نمایش فوکوس صفحه‌کلید حفظ شده است.

سکشن هفتم TrackRecord مطابق فریم 30:315 با پس‌زمینهٔ تمام‌عرض #121212 (رنگ فریم Landing در فیگما)، فاصلهٔ ۸۰ پیکسل از بخش قبلی و فضای داخلی بالا و پایین ۸۰ پیکسل اضافه شد. عنوان و توضیح وسط‌چین و آمار در ردیف ۸۶۱ پیکسلی با فاصلهٔ ۴۸ پیکسل هستند. مقادیر از راست 7+، 10+، 1001+ و 200.000 مطابق فیگما هستند و با bdi dir=ltr علامت مثبت در سمت راست عدد نمایش داده می‌شود. عدد 1000+ در درخواست مثال ترتیب علامت بود؛ مقدار واقعی طرح 1001+ حفظ شده است.

این سکشن هیچ انیمیشن ورود، شمارش، هاور یا transition ندارد. اعداد از فونت FaNum موجود با وزن ۸۰۰ استفاده می‌کنند؛ فایل وزن Black فیگما در فایل‌های ارسالی موجود نیست. خط‌های طلایی از SVG موجود بدون تغییر استفاده می‌کنند.

بررسی TypeScript، ساخت Vite، پنج تست تعامل hook و دو تست ساخت پیش‌نمایش موفق بودند. خروجی HTML مستقل و یکپارچگی ZIP بررسی شدند. بررسی بصری مرورگر و آزمون هاور در مرورگر به دلیل در دسترس نبودن سرویس پیش‌نمایش انجام نشده‌اند.

## نسخهٔ ۱۶ — علامت مثبت، ارتفاع کارنامه و فوتر

عدد و علامت مثبت در کارنامه به دو عنصر مستقل در inline-flex با direction:ltr تبدیل شدند. علامت مثبت با Arial و بدون وابستگی به شکل‌دهی فونت FaNum نمایش می‌یابد؛ مثبت در سمت راست عدد است. padding عمودی کارنامه از ۸۰ به ۱۲۰ پیکسل افزایش یافت و ارتفاع آن از ۴۲۸ به ۵۰۸ پیکسل رسید. این بخش همچنان هیچ انیمیشنی ندارد.

فوتر مطابق فیگما 42:507، با پس‌زمینهٔ تمام‌عرض #181818، فاصلهٔ ۸۰ پیکسل از کارنامه و ارتفاع ۴۲۹ پیکسل ساخته شد. لوگو، متن برند، سه ستون دسترسی سریع/خدمات/ارتباط و متن حق نشر طبق طرح هستند. ورود ملایم هنگام اسکرول از hook مشترک استفاده می‌کند. هاور هشت زیرمنو فقط تغییر رنگ ۲۶۰ میلی‌ثانیه‌ای به #D1C56C است؛ هاور دو آیکون فقط جابه‌جایی عمودی ۲ پیکسلی طی ۲۸۰ میلی‌ثانیه است. کاهش حرکت سیستم رعایت می‌شود. شماره و ایمیل لینک واقعی tel/mailto دارند و هاور تزئینی ندارند.

هر دو SVG ارسالی بدون تغییر کپی شدند. Vector (14).svg در رندر محلی فقط قاب گرد بیرونی دارد و جزئیات داخلی اینستاگرام در آن دیده نمی‌شود؛ دارایی اصلی دست‌کاری یا بازطراحی نشد. Social Icons.svg آیکون واتساپ است. لینک شبکه‌های اجتماعی ارائه نشده، بنابراین دکمه‌ها فعلاً tarhim:social با platform منتشر می‌کنند؛ باید هنگام اتصال صفحات، نشانی واقعی حساب‌ها داده شود. زیرمنوهای خدمات همان رویداد tarhim:service-details قبلی را منتشر می‌کنند. دسترسی سریع خدمات، پلن‌ها و آرشیو به سکشن فعلی اسکرول می‌کند و مراسم‌ها همان رویداد live هدر را دارد.

بررسی TypeScript، ساخت Vite، پنج تست hook و دو تست ساخت پیش‌نمایش موفق بودند. فایل پیش‌نمایش مستقل، SVGهای تعبیه‌شده و ZIP بررسی شدند. سرویس پیش‌نمایش مرورگر در دسترس نیست؛ تطبیق بصری و تعامل مرورگر تأیید نشده‌اند.

## نسخهٔ ۱۷

فقط آیکون اینستاگرام فوتر با فایل کامل Social Icons (1).svg ارسالی جایگزین شد. توضیح نسخهٔ قبلی دربارهٔ ناقص‌بودن این آیکون دیگر صدق نمی‌کند. سایر سورس‌ها و دارایی‌ها با نسخهٔ ۱۶ یکسان‌اند. ساخت و TypeScript موفق بودند؛ تصویر خود SVG رندر و بررسی شد و حضور آن در پیش‌نمایش مستقل تأیید شد.

## فاز ۶ در حال انجام

راهنمای محیط توسعه، گزارش ده مرحله و اطلاعات موردنیاز در docs/phase-06/ قرار دارند. npm run check برای TypeScript و هفت تست موجود است؛ npm run build خروجی dist را می‌سازد. محیط فعلی با Node 24.22.1 بررسی شد؛ نسخه در .node-version ثبت است. این لندینگ متغیر محیطی الزامی ندارد و .env.example فقط راهنماست.

مخزن Git محلی آماده است و در بستهٔ فاز ۶، online-tarhim-local.git.bundle برای بازیابی تاریخچه وجود دارد. Staging و remote هنوز آماده نیستند؛ این فاز کامل یا منتشرشده اعلام نمی‌شود. src و public نسبت به نسخهٔ ۱۷ تغییر نکرده‌اند.
